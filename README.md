# Monorepo 프로젝트 기본 
> Target의 Javascript 버전은 ES2022 이다.
> 개발 IDE는 Visual Studio Code를 사용한다.
> 웹서버와 DB서버는 로컬에서 테스트 한다.   

## 1. 프런트앤드 
- React 프레임워크를 이용한다.
- Bootstrap 을 프런트앤드 프레임워크로 사용한다. 

## 2. 백앤드
- Node.js 프레임워크를 이용한다.
- DB는 Oracle을 기본으로 사용한다. 

## 3. 공통
- 공통 모듈은 가능하면 사용하지 않는것으로 한다.
- Type은 공통으로 사용할 수 있다. 
 
## 4. 개발방향
1. Python 과 백앤드의 연동을 테스트한다.
2. Python에서 Machine Learning을 이용하여 AI 모델을 이용할 수 있다.
